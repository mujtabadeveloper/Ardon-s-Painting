# Ardon’s Painting

Responsive static website with animations and bundled photos. No build step or dependencies required.

## Preview
Open index.html in your browser, or run `python -m http.server 8000` in this folder.

## GitHub
Extract this ZIP, then upload the extracted files to the root of your GitHub repository. Keep the assets folder alongside index.html.

## Vercel
Import the GitHub repository. Choose Other as the framework. Leave Build Command blank and set Output Directory to `.` (repository root).

## GitHub Pages
In repository Settings > Pages, deploy from the main branch and root folder.

## Contact form
The quote form opens the visitor’s email app with a prepared message. It does not submit to a backend.

## Images
Photos are bundled locally. Gallery images are inspiration photography, not completed client projects. Google Fonts requires internet access; system font fallbacks are included.
